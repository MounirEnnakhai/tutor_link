## 🏗️ Architecture

```
lib/
├── core/
│   ├── constants/        # App-wide constants (strings, collections, spacing)
│   ├── errors/           # Failure classes (Clean Architecture)
│   ├── extensions/       # Dart/Flutter extension methods
│   ├── router/           # GoRouter configuration + route names
│   ├── theme/            # Material 3 light & dark themes
│   ├── utils/            # Validators, localizations
│   └── widgets/          # Shared UI components (AppButton)
│
├── data/
│   ├── datasources/
│   │   ├── auth/         # Firebase Auth data source
│   │   ├── firestore/    # Firestore data sources (tutor, offer, review)
│   │   └── storage/      # Firebase Storage data source
│   ├── models/           # Firestore-serializable models (extends entities)
│   └── repositories/     # Repository implementations
│
├── domain/
│   ├── entities/         # Pure Dart entities (UserEntity, TutorEntity, …)
│   ├── repositories/     # Abstract repository interfaces
│   └── usecases/         # Business logic use cases
│
├── presentation/
│   ├── providers/        # Riverpod providers (auth, tutor, theme, search)
│   ├── screens/
│   │   ├── auth/         # Login, Register, Splash
│   │   ├── student/      # Home, Search, Map, Favorites, Profile, Review
│   │   ├── tutor/        # Dashboard, Edit Profile, Create/Manage Offers
│   │   └── admin/        # Dashboard, User Management, Verification
│   └── widgets/
│       ├── common/       # AppButton, AppTextField, ShimmerLoading
│       ├── tutor_card/   # TutorCard (horizontal + vertical variants)
│       └── offers/       # OfferCard
│
├── firebase_options.dart  # Generated by FlutterFire CLI
└── main.dart
```

**Pattern:** Clean Architecture + Repository Pattern  
**State Management:** Riverpod 2 (providers, StateNotifier, StreamProvider, FutureProvider)  
**Navigation:** GoRouter with auth-guarded redirects  
**UI:** Material Design 3, custom Poppins font, dark mode support

## 🚀 Getting Started

### Prerequisites

- Flutter **3.19+** (`flutter --version`)
- Dart **3.3+**
- A Firebase project
- Google Maps API key
- Android Studio / VS Code with Flutter plugin

### 1. Clone & Install

```bash
git clone https://github.com/your-org/tutorlink.git
cd tutorlink
flutter pub get
```

### 2. Firebase Setup

```bash
# Install FlutterFire CLI
dart pub global activate flutterfire_cli

# Configure Firebase (follow the prompts)
flutterfire configure
```

This generates `lib/firebase_options.dart` automatically.

Enable these Firebase services in your project console:
- **Authentication** → Email/Password + Google Sign-In
- **Cloud Firestore** → create database in production mode
- **Cloud Storage** → default bucket
- **Cloud Messaging** → for future push notifications

### 3. Firestore Indexes

Deploy the included rules and required indexes:

```bash
firebase deploy --only firestore:rules
firebase deploy --only storage
```

Required Firestore composite indexes (create in Console):
| Collection | Fields |
|---|---|
| `tutors` | `isActive ASC`, `verificationStatus ASC`, `rating DESC` |
| `tutors` | `subjects ASC`, `rating DESC` |
| `offers` | `tutorId ASC`, `status ASC` |
| `offers` | `status ASC`, `createdAt DESC` |
| `reviews` | `tutorId ASC`, `isVisible ASC`, `createdAt DESC` |
| `favorites` | `studentId ASC` |
| `verification_requests` | `status ASC`, `createdAt DESC` |

### 4. Google Maps API Key

**Android** — `android/app/src/main/AndroidManifest.xml`:
```xml
<meta-data
    android:name="com.google.android.geo.API_KEY"
    android:value="YOUR_GOOGLE_MAPS_API_KEY"/>
```

**iOS** — `ios/Runner/AppDelegate.swift`:
```swift
import GoogleMaps
// In application(_:didFinishLaunchingWithOptions:):
GMSServices.provideAPIKey("YOUR_GOOGLE_MAPS_API_KEY")
```

Enable these APIs in [Google Cloud Console](https://console.cloud.google.com):
- Maps SDK for Android
- Maps SDK for iOS
- Places API
- Geocoding API
- Geolocation API

### 5. Fonts

Download Poppins from [Google Fonts](https://fonts.google.com/specimen/Poppins) and place in `assets/fonts/`:
```
assets/fonts/
├── Poppins-Regular.ttf
├── Poppins-Medium.ttf
├── Poppins-SemiBold.ttf
└── Poppins-Bold.ttf
```

### 6. Run

```bash
flutter run
```

## 🔥 Firestore Data Structure

```
users/{userId}
  email, fullName, photoUrl, role, isEmailVerified,
  isActive, phoneNumber, createdAt, updatedAt

tutors/{tutorId}           # tutorId == userId for tutors
  userId, fullName, photoUrl, biography, subjects[],
  educationLevel, qualifications[], yearsOfExperience,
  teachingLanguages[], rating, totalReviews, totalStudents,
  location { latitude, longitude, city, country, geoPoint },
  phoneNumber, email, verificationStatus,
  teachingModes[], certifications[], isActive, createdAt

offers/{offerId}
  tutorId, tutorName, tutorPhotoUrl, subject, title,
  description, type (privateLesson|groupClass), status,
  hourlyRate?, teachingMode?, availabilitySchedule[],
  monthlyPrice?, maxStudents?, availableSeats?, isOnline?,
  classSchedule[], location, latitude, longitude,
  imageUrl, tags[], createdAt, updatedAt

reviews/{reviewId}
  tutorId, studentId, studentName, studentPhotoUrl,
  rating, comment, isVisible, createdAt

favorites/{favoriteId}
  studentId, tutorId

verification_requests/{requestId}
  tutorId, documents[], status, rejectionReason?,
  createdAt, reviewedAt?
```

| Role | Access |
|---|---|
| **Student** | Browse, search, map, favorites, contact, review |
| **Tutor** | Dashboard, create/manage offers, edit profile, request verification |
| **Admin** | All of the above + user management, verify tutors, moderation |

## 🌍 Localization

Supports **English**, **French**, and **Arabic** out of the box.  
Add more keys in `lib/core/utils/app_localizations.dart`.

For full RTL support with Arabic, the `Directionality` widget is handled automatically by Flutter's localization system.
